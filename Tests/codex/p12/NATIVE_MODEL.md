# P12 real-C native boundary

This is host software evidence, not ARM, electrical, timing, concurrency or silicon certification. Vendor files stay unchanged. The standalone project is `Firmware/Tests/codex/hal/native32/`; all build/evidence directories are sibling `../ffb-test-build/codex-p12-*` paths.

## Execution and access boundary

Installed Clang multilib compiles the checked-in source as C, with real 32-bit pointers and supplied CMSIS structures/constants. Only application-side CPU/compiler intrinsics are replaced. Eight MAP_PRIVATE|MAP_ANONYMOUS|MAP_FIXED_NOREPLACE windows are ordinary process RAM at numeric device addresses; there is no hardware or device-file mapping. Mapping conflicts fail. Fixtures clear every window, bus queue, callback counter (within each relevant fixture), event source and public HAL time state. FLASH backing starts erased.

C load/store callbacks use the Clang kernel-address instrumentation ABI. Stack/global/shadow checking and access deduplication are disabled so consecutive volatile accesses remain observable. This is **not ASan memory-safety checking**. Genuine native32 UBSan is a separate option. The earlier 64-bit project supplies genuine GCC/Clang ASan/UBSan checks on its own bounded real-C and C++ adapter paths; these are separate evidence sets.

A store callback occurs before the CPU store. The observer records its address, width and old word, then finalizes effects at the next C access or explicit flush. C++ fixtures inject hardware inputs or inspect backing/request state; they must flush before injecting over or observing a final outstanding C store. Ordinary RAM callbacks only flush pending effects. Coverage notes/counters are emitted separately by llvm-cov/gcov instrumentation. Stale counters are removed before each verified run.

## Modeled behavior and independent controls

Primary register definitions: supplied CMSIS device headers. Behavioral references: supplied RM0090 Rev 22 GPIO chapter 8, EXTI chapter 12, DMA chapter 10, ADC chapter 13, timers chapters 17/18, I2C chapter 27, SPI chapter 28, USART chapter 30, CAN chapter 32, USB OTG chapters 34/35, plus FLASH/RCC/PWR register sections. These chapter references identify the model's basis, not a claim to implement every register or every device variant. GPIO errata qualifications remain in REGISTER_MODEL_DESIGN/REFERENCES. Every added effect must retain its narrower limits below.

| Boundary | Implemented subset | Direct discrimination / limits |
|---|---|---|
| GPIO | BSRR request/effect with set priority, BSRR read zero; stable lock key sequence and protected configuration fields | Consecutive writes, incorrect lock mask, HAL set/reset/toggle/lock cases; earlier dedicated C++ model has broader lock/error controls. Electrical inputs and erratum PH10/PI10 routing are not simulated in this native model. |
| EXTI | PR W1C, SWIER pending gated by IMR, PR clear resets SWIER | Preserves unrelated pending bits and masked SWI control; scratch W1C corruption fails ordinary assertions. No asynchronous edge detector or NVIC arbitration. |
| FLASH | Main/option key protocols, SR W1C, program backing can only clear bits, abstract completion BSY/EOP | Wrong/incomplete keys, width/neighbor guards, IRQ/error/option request checks. Sector/mass erase is a request trace, not a simulated silicon erase. Option programming is volatile request/readback, not persistent fuses or reset behavior. |
| DMA | IFCR status clearing; explicit enabled/busy stream completion, width/increment/direction/address copy; normal/circular/double-buffer count/CT changes and completion flag | Inactive/requestless ADC controls, memory-copy width/increment checks, real peripheral callback chains. UART/SPI/I2C/ADC requests/data are checked. Timer request scheduling, bus arbitration, FIFO packing, transfers with different memory/peripheral widths, abort latency and illegal address accesses are not complete hardware models. Do not use unsupported combinations as silicon oracles. |
| I2C | SR1 error W0C, SR1→SR2 ADDR clear, DR read/write effects; explicit 7-bit acknowledging/NACK peer and supplied receive bytes | Status-pair, wrong-address and peer-output controls; normal TXE versus delayed BTF regression distinguished. Peer completion is abstract and can represent delayed service. No analog filtering, arbitration timing or 10-bit external peer model. Slave tests inject documented events directly. |
| SPI | Distinct explicit receive queue, TX retirement, CRCERR W0C, DR→SR overrun and SR→CR1 mode-fault clear | FIFO word controls, W0C/read-sequence controls, word-width and duplex tests. No CRC engine, waveform or clock phase simulation. FRE read-clear and all slave timing variants remain unmodeled. |
| USART | Explicit receive queue and DR/RXNE, SR→DR idle/error clear, transmit-ready/complete abstract retirement, SR write-zero handling | Idle polling/IT/DMA, nine-bit/parity and callback order checks. No baud timing, physical parity generation or interrupt preemption. |
| ADC / TIM | Status W0C; ADC DR read clears EOC; explicit conversion/capture/status inputs | Conversion/event/state/IRQ/DMA cases. No analog conversion or counter/waveform generator; DMA event injection is explicit, not a timer simulator. |
| USB | FIFO packet-word input, GRXSTSP pops RX level, GRSTCTL commands self-clear and preserve idle input, global/endpoint/host W1C subsets, read-only aggregate status, force-mode status and host-channel halt | Guarded partial reads, request/data/IRQ cases, read-only status and reset-command controls. Endpoint aggregate levels are supplied consistently by fixtures rather than fully derived. No USB link, handshake/retry timing, SOF clock or real DMA engine; dedicated endpoint/HS/isochronous behavior requires separate coverage. |
| CAN | Explicit acknowledgement/event inputs; TSR completion-group and MSR interrupt W1C subsets | Per-mailbox completion/abort and arbitration-loss dispatch. Receive FIFO level/release, arbitration/error counters and CAN frame timing are not a full bus model. |
| RCC / PWR / watchdog / CPU | Explicit readiness events, bit-band write translation; request/register readback, recorded WFI/WFE/barriers and supplied NVIC register input | Positive/timeout pairs, prescaler/frequency math and request controls. No real oscillator, watchdog reset, MPU enforcement, sleep, priority/preemption or system reset. Counted waits need explicit already-ready or timeout controls; GetTick event hooks do not run in every counted loop. |

Unsupported or omitted semantics are not silently promoted to hardware fidelity by a passing test. Tests that inspect a request use request wording. The model still has generic storage for register fields outside the explicit effects above; such accesses establish only software requests/readback, never unspecified peripheral behavior.

## Full assertions

`P12_FULL_ASSERT=ON` enables the supplied HAL assert_param definitions. Optional LL ADC expects an application-owned stm32_assert.h absent from this checkout; the owned boundary header reproduces the same assert_failed contract. Unplanned assertions print a diagnostic and abort. Two explicitly armed negative tests translate that boundary into a distinct C++ exception, then verify no register configuration happened. They prove the configuration is active. Production-configuration runtime input checks remain a separate claim.

This gate found and corrected six owned OC fixtures that had supplied a PWM mode to the output-compare API. It did not change vendor assertions or skip those cases.
