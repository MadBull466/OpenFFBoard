## Environment

The exact configure / build / run / sanitizer / coverage commands are those of `Tests/Code_Coverage/claude/plans/PROGRESS.md` "Environment" (source of truth for the toolchain). Integration additions:

- Build directories: `../ffb-test-build/it-<variant>` (`default`, `m32`, `san`, `clang`, `clang-san`, `nodsp`, `nodsp-san`, `cov`); audit and review copies under `../ffb-test-build/audit/`.
- Gate of a work order: `python3 -B Firmware/Tests/Integration_Tests/tools/it_gate.py --wo <ID> --variants default,m32`; phase gate: add `--full --isolated` (isolated = HEAD plus this WO's files, built in `../ffb-test-build/it-iso-<WO>`; `--own-build` for parallel writers). Evidence: `../ffb-test-build/it-gate/<WO>/latest.json`. At most 10 jobs (`--jobs`); a case that runs longer than 120 s ends the process (`FFB_IT_CASE_TIMEOUT_S`; 0 = off).
- A run of one case: `FFB_IT_CASE_TIMEOUT_S=0 ../ffb-test-build/it-default/ffb_integration_tests -tc="<name>"`; sanitizer runs of the cases that delete the main class need `--no-skip` and `ASAN_OPTIONS=new_delete_type_mismatch=0`.
- Run directly: `../ffb-test-build/it-default/ffb_integration_tests` (`-tc="[F1-E5]*"` for one requirement).
- Integration bug report: `python3 -B Firmware/Tests/Integration_Tests/tools/make_integration_bug_report.py`.
